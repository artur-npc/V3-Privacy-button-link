Privacy Button — US framework Case A · Show on all pages

Privacy Button rendering for the US framework when "Show CMP on page load" is disabled.

Test cases: A · Show on all pages B · Specific pages — match C · Specific pages — no match

Configuration required (Admin Interface)

  • Settings type: US framework (CCPA / US Privacy)
  • Privacy Trigger → Layout: Privacy Button
  • Settings: Position Bottom Right, Show on all pages
  • "Show CMP on page load" → DISABLED (ccpa.showOnPageLoad = false)
Replace YOUR_US_SETTINGS_ID at the bottom of this file with the settingsId of a US configuration set up exactly as above.

Expected result

✅ Pass
First-layer banner stays hidden (Show CMP disabled), but the floating Privacy Button appears bottom-right and opens the consent layer.
❌ Fail
Nothing renders on page load — the Privacy Button does not appear bottom-right.

Privacy Trigger — Privacy Link variant

If the Admin "Privacy Trigger" layout is set to Privacy Link instead of Privacy Button, no floating button renders — the integrator places this link. Use it to verify the Privacy Link layout on the same config.
